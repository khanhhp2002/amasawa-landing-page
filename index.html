A few details

Before you build.

Where we are today, and where we’re heading next.

What is Amasawa?

Amasawa is an independent development initiative focused on Unity tools and reusable game development assets for indie developers and small studios.

Can I download the toolkits yet?

Public releases are not available yet. This page introduces our development direction. You can reach out by email to ask about progress or share a workflow you’d like us to improve.

How will Claude be used?

We plan to use the Claude API for C# script assistance, code explanations, debugging guidance, and repetitive workflow planning. The integration is planned and is not currently a released product.

Which Unity versions and platforms will be supported?

Compatibility will be documented for each package when it is released, including supported Unity versions, render pipelines, and target platforms.

What keeps slowing you down?

Tell us about a repetitive Unity task, a missing utility, or a component you wish you could reuse. Help shape what we build next.
