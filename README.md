# Amasawa landing page

A responsive English landing page for Amasawa's Unity tools and reusable assets. Plain HTML, CSS, and JavaScript. No installation, build step, external fonts, analytics, or API keys.

## Preview

Open `index.html` directly, or run `python -m http.server 8080` in this folder and visit `http://localhost:8080`.

## Publish on GitHub Pages

1. Create a new public repository named `amasawa-landing-page` under your GitHub account. Keep this separate from existing projects.
2. Put `index.html`, `favicon.svg`, and `.nojekyll` at the root of the `main` branch. `README.md` is optional.
3. In the repository, go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/ (root)**, then **Save**.
4. Wait for the Pages deployment to finish. For account `khanhhp2002` and the suggested repository name, the expected URL is `https://khanhhp2002.github.io/amasawa-landing-page/`. Check the deployed URL before putting it in a company website field.

The URL above is an expected destination, not confirmation of publication.

## Content and maintenance

- Company name and product direction follow the supplied application context.
- Toolkit categories are proposed product focus areas, not claims of existing public releases.
- Claude API integration is explicitly described as planned. No partnership, customers, funding, performance metrics, or released AI features are claimed.
- The editor is an interactive illustrative preview. Its snippets are not downloadable products or an actual Unity plugin.
- The contact action opens the connected developer's verified GitHub profile. There is no form or mailing list backend.
- Edit the HTML for product updates, actual release links, compatibility, or a company contact address.
- The site works from a repository subpath through relative asset links and section anchors.

## Included behavior

Responsive navigation with an accessible mobile menu, keyboard-operable code example tabs, FAQ disclosure controls, reduced-motion handling, and basic search/social metadata.
